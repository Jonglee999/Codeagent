# CodeAgent

AI-powered coding assistant with multi-agent orchestration.

## Quick Start

```bash
# Create virtual environment and install dependencies
uv venv
uv sync

# Install dev dependencies
uv sync --group dev

# Verify setup
python -m pytest tests/ -x -q
```
